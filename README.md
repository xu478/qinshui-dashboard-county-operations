# 沁水县供应链智慧运营指挥大屏 · 县域运营版

这是从原站独立复制的新版本，不修改原仓库或原 GitHub Pages 页面。项目为纯静态网站，可直接由 GitHub Pages 从 `main` 分支根目录发布。

## 本版调整

- 配送地图在“沁水供应链园区”五角星所在的龙港镇区域内显示 9 个黄色门店光点。门店光点呼吸闪烁，园区到门店之间有细闪运输流线；整个网络由龙港镇真实 SVG 边界裁剪，不会越出该乡镇区域。
- 门店销售图使用对数横轴，让金额较小的前三家门店获得更清晰的横向长度；梅河店图形上限为 30,000 元，标签始终显示真实金额。
- 天气通过 Open-Meteo 公共接口读取沁水县实时实况与未来 7 天预报，每 10 分钟刷新一次。需求与农业建议依据当前预报生成多条县域经营提示，每 5 秒轮播。
- 地图仓储信息调整为：分拣拆零 13,000 个、地堆区 2,050 个、库区数 10 个、当前存储量 53.2 吨。
- 销售趋势图不再显示 10 月 1—5 日实际金额、截止日期和完成比例，只保留完整月份实绩与后续预估。
- 天气模块不再显示底部旧数据/获取时间说明行。
- 商品维度的未来 7 天销售额、数量和指数区间下调为县域门店运营规模。

## 本地预览

在项目根目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

## 数据说明

实时天气使用公开的 Open-Meteo API，不在前端存放密钥。ERP、订单和消费者数据仍为原站随包提供的匿名汇总或演示数据；页面没有接入生产数据库。地图中心红星与区域内门店光点是运营示意，不代表实时车辆轨迹或已核实的每家门店经纬度。
